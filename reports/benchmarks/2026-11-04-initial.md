## Follow-up: DeepSeek API, 2026-11-05

The original DeepSeek provider used `previous_response_id`, but DeepSeek's Responses API is stateless. A live tool round trip failed with `No tool call found for tool output with call_id`. Athena now retains and sends the full input/output history for DeepSeek. The live `get_time` tool round trip succeeded after the change; OpenAI's stateful path remains separate.

With the same temporary τ-bench adapter, `deepseek-chat` as the Athena agent model and simulated user, airline task IDs `0 1 2 3 4` (one trial each, max 30 steps, substring communication scorer) scored **4/5**. Task 1 failed its database check despite completing the two expected read actions and calling `cancel_reservation`; the transcript shows a final cancellation confirmation, so the remaining mismatch needs task-state inspection. All five runs terminated normally and there were no infrastructure errors. Raw results: `/private/tmp/athena-tau2-bench/data/simulations/athena-deepseek-airline-5/results.json`.

This five-task smoke test does not use the TUI approval gate and is not comparable with the official full text-v1 leaderboard, which has a frozen task set and official scoring configuration. No leaderboard submission was made.
